# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 0.15    | :white_check_mark: |
| 0.14    | :white_check_mark: |
| 0.13    | :x:                |
| < 0.13  | :x:                |

## Reporting a Vulnerability

Please report vulnerabilities privately using the github 'Security and quality'
tab for this project. Please refer to the following documentation:

https://docs.github.com/en/code-security/how-tos/report-and-fix-vulnerabilities/report-privately

Reports will be responded to as quickly as possible; ideally, you will receive 
an initial reply within 24 hours.
